# 👑 جنگ سلسله — بازی استراتژی فتح جهان

یک بازی استراتژیک تکنفره‌ی فارسی در دوران باستان، ساخته‌شده از روی سند طراحی بازی «جنگ سلسله» (فایل `text(1).txt`).

## 🌐 بازی آنلاین (گوشی و کامپیوتر)

▶️ **[https://seiveroz.github.io/-/](https://seiveroz.github.io/-/)** — بدون نصب، مستقیم در مرورگر (اندروید، iOS، دسکتاپ)

## 🎮 داستان بازی

شما پادشاه یک حکومت باستانی هستید. هدف شما فتح **هر ۶ سرزمین مادر جهان** و تبدیل شدن به تنها **«فاتح جهان»** است:

🏛️ ایرانشهر • 🦅 روم • ⚔️ اسکاندیناوی • 🕌 سرزمین اعراب • 🐉 سرزمین کره • 👑 اروپا

- انتخاب شخصیت تاریخی (۸۰+ شخصیت مثل کوروش، ایوار، صلاح‌الدین، ناپلئون و…)
- انتخاب حکومت (۷۰+ حکومت مثل تخت جمشید، کاته‌گات، روم و…)
- اقتصاد فقط با **طلا** (معدن، بازار، کاروان، بندر)
- ارتش با ۱۱ نوع سرباز و راهبردهای مختلف حمله (تصرف، غارت، محاصره، ترور، حمله مخفی)
- قلعه و دیوار دفاعی (۲۰ سطح)
- قهرمانان (۲۰ قهرمان)، سپر دفاعی، رضایت مردم، رخدادهای زنده (۱۰۰+ رخداد)
- **موسیقی حماسی/کهن پس‌زمینه** (تولید زنده با Web Audio — بدون فایل صوتی، کاملاً آفلاین) با دکمه روشن/خاموش 🎵
- گزارش شبانه، رتبه‌بندی روزانه، ۶ حریف هوش مصنوعی، فصل ۱۴ روزه

## 💻 نحوه نصب روی ویندوز

1. فایل **`build/Jang-Selseleh-Setup.exe`** را دانلود و اجرا کنید.
2. بازی به‌صورت خودکار در `%LOCALAPPDATA%\JangSelseleh` نصب می‌شود و میان‌بر «جنگ سلسله» روی دسکتاپ و منوی استارت ساخته می‌شود.
3. برای اجرا کافی است روی میان‌بر دسکتاپ دوبار کلیک کنید (بازی در پنجره‌ی مستقل مرورگر Edge باز می‌شود).
4. حذف بازی از «حذف برنامه‌ها» یا با اجرای `JangSelseleh.exe --uninstall`.

> ⚠️ نکته: چون فایل به‌صورت شخصی ساخته شده و امضای دیجیتال ندارد، ممکن است Windows SmartScreen هشدار «ناشر ناشناس» بدهد. روی **More info → Run anyway** کلیک کنید.

## 🌐 اجرای بدون نصب (مرورگر)

- فایل `build/Jang-Selseleh-Game-Portable.zip` را باز کنید و `index.html` را در هر مرورگر مدرن (Chrome / Edge / Firefox) باز کنید.
- یا از پیش‌نمایش زنده استفاده کنید: `node server.js` و سپس `http://localhost:8080`

## 🕹️ راهنمای کوتاه

| بخش | توضیح |
| --- | --- |
| 🗺️ نقشه جهان | کلیک روی هر سرزمین → حمله (از روز ۳ فصل) |
| 🏛️ حکومت من | ساخت ساختمان، ارتقای قلعه و دیوار دفاعی |
| ⚔️ ارتش | خرید ۱۱ نوع سرباز (ظرفیت با ارتقای قلعه بیشتر می‌شود) |
| 🦸 قهرمانان | استخدام قهرمان و خرید سپر دفاعی |
| 📰 اخبار | اخبار جهان و گزارش‌های شما + برترین‌های روز |
| 🌙 پایان روز | درآمد روزانه، رتبه‌بندی، حرکت حریفان، رخدادها |

## 🏆 شرایط برد

هر ۶ سرزمین را ۱۰۰٪ فتح کنید تا «فاتح جهان» شوید. فصل ۱۴ روز طول می‌کشد و در پایان فقط یک نفر برنده است.

## 🛠 ساخت مجدد exe

```bash
# پیش‌نیاز: نصب Zig (مثلاً از PyPI: pip install ziglang)
ZIG=/path/to/zig bash tools/build.sh
```

## 📁 ساختار پروژه

```
game/            ← سورس بازی (HTML/CSS/JS)
desktop/         ← پیکربندی Electron (اختیاری) و آیکون
tools/           ← ساخت نصب‌کننده ویندوز (Zig + C)
build/           ← خروجی‌ها (Setup.exe و Portable.zip)
server.js        ← سرور پیش‌نمایش زنده
text(1).txt      ← سند طراحی اصلی بازی
```
